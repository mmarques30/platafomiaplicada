
# Correção: Google Login em Domínio Próprio

## Problema Identificado

O erro 404 ocorre na URL:
```
https://plataforma.iaplicada.com/~oauth/initiate?provider=google&redirect_uri=...
```

A biblioteca `@lovable.dev/cloud-auth-js` redireciona para `/~oauth/initiate`, um endpoint que é **provisionado automaticamente apenas nos domínios Lovable** (`*.lovable.app`). Em domínios próprios, essa rota não existe, causando o 404.

### Como Funciona

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ DOMÍNIO LOVABLE (*.lovable.app)                                         │
│                                                                          │
│  /~oauth/initiate  ─►  Proxy Lovable  ─►  OAuth Broker  ─►  Google      │
│                        (automático)                                      │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ DOMÍNIO PRÓPRIO (plataforma.iaplicada.com)                              │
│                                                                          │
│  /~oauth/initiate  ─►  404 (rota não existe)                            │
└─────────────────────────────────────────────────────────────────────────┘
```

## Solução

Para domínios próprios, precisamos **configurar o `oauthBrokerUrl`** para apontar diretamente para o OAuth Broker do Lovable (hospedado em `oauth.lovable.app`) em vez de usar a rota relativa `/~oauth/initiate`.

### Opção Recomendada

Detectar automaticamente se está em domínio próprio e usar a URL correta do broker:

```typescript
// src/integrations/lovable/index.ts
import { createLovableAuth } from "@lovable.dev/cloud-auth-js";
import { supabase } from "../supabase/client";

// Detectar se é domínio Lovable ou próprio
const isLovableDomain = 
  window.location.hostname.includes("lovable.app") ||
  window.location.hostname.includes("lovableproject.com");

// Para domínios próprios, usar URL absoluta do broker
const lovableAuth = createLovableAuth({
  oauthBrokerUrl: isLovableDomain 
    ? "/~oauth/initiate" 
    : "https://platafomiaplicada.lovable.app/~oauth/initiate",
});
```

## Alterações Necessárias

### Arquivo: `src/integrations/lovable/index.ts`

**Modificar** a criação do `lovableAuth` para detectar o domínio e usar a URL apropriada do broker OAuth:

```typescript
// This file is auto-generated by Lovable. Do not modify it.

import { createLovableAuth } from "@lovable.dev/cloud-auth-js";
import { supabase } from "../supabase/client";

// Detectar se está em domínio Lovable nativo
const isLovableDomain = 
  typeof window !== "undefined" && (
    window.location.hostname.includes("lovable.app") ||
    window.location.hostname.includes("lovableproject.com")
  );

// Para domínios próprios, usar URL absoluta do broker via domínio Lovable
const lovableAuth = createLovableAuth({
  oauthBrokerUrl: isLovableDomain 
    ? "/~oauth/initiate" 
    : "https://platafomiaplicada.lovable.app/~oauth/initiate",
});

export const lovable = {
  auth: {
    signInWithOAuth: async (provider: "google" | "apple", opts?: { redirect_uri?: string }) => {
      const result = await lovableAuth.signInWithOAuth(provider, {
        ...opts,
      });

      if (result.redirected) {
        return result;
      }

      if (result.error) {
        return result;
      }

      try {
        await supabase.auth.setSession(result.tokens);
      } catch (e) {
        return { error: e instanceof Error ? e : new Error(String(e)) };
      }
      return result;
    },
  },
};
```

## Resultado Esperado

1. Usuário em `plataforma.iaplicada.com` clica em "Entrar com Google"
2. É redirecionado para `platafomiaplicada.lovable.app/~oauth/initiate` (onde o broker existe)
3. Broker inicia fluxo OAuth com Google
4. Google autentica e redireciona de volta para `plataforma.iaplicada.com/auth`
5. Página `/auth` processa os tokens e redireciona para `/selecionar-ambiente`

## Detalhes Técnicos

| Parâmetro | Valor |
|-----------|-------|
| `oauthBrokerUrl` (domínio Lovable) | `/~oauth/initiate` |
| `oauthBrokerUrl` (domínio próprio) | `https://platafomiaplicada.lovable.app/~oauth/initiate` |
| `redirect_uri` | `https://plataforma.iaplicada.com/auth` |
